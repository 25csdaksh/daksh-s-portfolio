C Language — Full Short Notes

A complete, beginner-friendly reference for revision: syntax, data types, control flow, functions, pointers, memory, and file handling — with a plain-English explanation before every code block.

01

What is C

In plain terms: C is a general-purpose, procedural programming language created in 1972 by Dennis Ritchie. It's called a "middle-level" language — close enough to hardware to manage memory directly, but readable enough for humans. Most modern languages (C++, Java, Python's interpreter, even parts of an OS kernel) are influenced by or built using C.
  • Procedural — code runs as a sequence of instructions inside functions
  • Compiled — source code is translated to machine code before running
  • Statically typed — every variable's type is fixed at compile time
  • Gives direct access to memory via pointers
02

Program Structure

Every C program needs at least one function called main() — that's where execution starts. #include pulls in ready-made code (like printf) from library files.
#include <stdio.h>  // bring in input/output functions

int main() {
    printf("Hello, World!");  // print text to screen
    return 0;  // tells OS the program ended successfully
}

04

Variables & Constants

A variable is a named box in memory that can hold a value and change over time. A constant is a box whose value is locked once set.
int age = 21;              // variable — can change
const float PI = 3.14;       // constant — cannot change
#define MAX 100              // preprocessor constant
05

Input / Output

printf displays output; scanf reads input from the keyboard. Both use format specifiers like %d to know what type of data to handle.
int num;
printf("Enter a number: ");
scanf("%d", &num);   // & gives the memory address of num
printf("You entered %d", num);

07

Conditional Statements

These let the program choose different paths depending on whether a condition is true or false.
if (age >= 18) {
    printf("Adult");
} else {
    printf("Minor");
}

switch (grade) {
    case 'A': printf("Excellent"); break;
    default: printf("Invalid");
}
08

Loops

Loops repeat a block of code while a condition holds — used for counting, iterating over data, or repeating a task until done.
for (int i = 0; i < 5; i++) {   // runs exactly 5 times
    printf("%d ", i);
}

while (n > 0) {                 // checks condition BEFORE running
    n--;
}

do {
    n++;
} while (n < 5);            // runs body at least once, checks AFTER
09

Jump Statements

These break the normal top-to-bottom flow of execution.
  • break — exits a loop or switch immediately
  • continue — skips to the next loop iteration
  • goto label; — jumps to a labeled line (rarely used, hurts readability)
  • return — exits a function, optionally sending back a value
10

Functions

A function is a named, reusable block of code. It can take inputs (parameters) and send back an output (return value), which keeps programs organized and avoids repeating code.
int add(int a, int b) {   // declaration + definition
    return a + b;
}

int main() {
    int sum = add(3, 4);       // calling the function
}

12

Arrays

An array stores multiple values of the same type under one name, in a contiguous block of memory, accessed by index (starting at 0).
int nums[5] = {10, 20, 30, 40, 50};
printf("%d", nums[0]);   // prints 10 — first element

int matrix[2][3];          // 2D array: 2 rows, 3 columns
13

Strings

C has no built-in string type — a string is just a char array ending in a null character '\0' that marks where it stops.
char name[] = "Alex";     // stored as A l e x \0
strlen(name);            // length, excluding \0
strcpy(dest, name);     // copy string
strcat(a, b);            // join/concatenate strings
strcmp(a, b);            // compare, returns 0 if equal
14

Pointers

A pointer is a variable that stores a memory address instead of a normal value. & gets an address; * follows a pointer to reach the value it points to. This is the feature that gives C its low-level power.
int x = 10;
int *p = &x;        // p now holds the address of x
printf("%d", *p);  // *p "dereferences" p → prints 10
Rule of thumb: & means "address of", * means "value at this address".
15

Dynamic Memory

Normal variables live on the stack and are cleaned up automatically. Dynamic memory is requested from the heap at runtime with malloc/calloc, and must be released manually with free — otherwise it causes a memory leak.
code
instructions
stack
local vars
heap
malloc / free
int *arr = (int *)malloc(5 * sizeof(int));  // request memory for 5 ints
free(arr);   // release it back when done
16

Structures

A struct groups related variables of different types under one name — useful for modeling a real-world "thing" like a student or point.
struct Student {
    char name[30];
    int age;
};

struct Student s1 = {"Sam", 20};
printf("%s", s1.name);  // . accesses a member
17

Unions

A union looks like a struct but all members share the same memory — only one member holds a valid value at a time. Useful for saving memory when you only need one of several types at once.
union Data {
    int i;
    float f;
};  // size = size of largest member, not the sum
18

Preprocessor Directives

Lines starting with # run before compilation — they edit the source text itself (inserting files, replacing macros, or including/excluding code blocks).
#include <stdio.h>   // include a header file
#define PI 3.14      // text substitution macro
#ifdef DEBUG ... #endif  // conditional compilation
19

File Handling

C reads/writes files through a FILE pointer. Always check that the file opened successfully, and close it when done to flush data and free resources.
FILE *fp = fopen("data.txt", "w");  // open for writing
if (fp != NULL) {
    fprintf(fp, "Hello file");
    fclose(fp);   // always close what you open
}

Modes: "r" read, "w" write (overwrite), "a" append, "r+" read & write.

Best Practices

  • Always initialize variables before use
  • Check malloc/fopen return values for NULL before using them
  • free() everything you malloc() — pair every allocation with a release
  • Avoid goto — prefer loops and functions for control flow
  • Use meaningful variable names, not single letters (except loop counters)
  • Compile with warnings on (-Wall) and fix them, don't ignore them
