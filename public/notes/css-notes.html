A complete, condensed reference for revision: selectors, the box model, layout systems, typography, motion, and responsive design — one page, dark mode, built for quick scanning.

01

What is CSS { }

CSS (Cascading Style Sheets) styles and lays out HTML elements — colors, fonts, spacing, positioning, responsiveness, and animation. "Cascading" refers to the rules that decide which style wins when several apply to the same element.

02

04

Pseudo-classes & Pseudo-elements

  • State: :hover :focus :active :visited
  • Structural: :first-child :last-child :nth-child(n)
  • Elements: ::before ::after ::first-line ::first-letter
05

Specificity

Low to high priority:

* < element < class/attribute/pseudo-class < ID < inline style < !important
Keep specificity low overall — it makes overrides and maintenance far easier later.
06

Colors & Units

  • Colors: name, #hex, rgb(), rgba(), hsl(), hsla()
  • Absolute units: px, pt, cm
  • Relative units: %, em (parent font), rem (root font), vw/vh (viewport)
07

Box Model

margin
border
padding
content
  • width / height — content size
  • padding — space inside the border
  • border — edge around padding
  • margin — space outside the border
box-sizing: border-box; /* width/height now include padding & border */
08

Display Property

ValueBehavior
blockFull width, starts on a new line
inlineOnly as wide as content, no new line
inline-blockInline flow but accepts width/height
noneHidden, removed from layout entirely
flexEnables flexbox on children
gridEnables grid layout on children
09

Position Property

ValueBehavior
staticDefault, normal document flow
relativeOffset relative to its own default position
absoluteRelative to nearest positioned ancestor
fixedRelative to viewport, stays put on scroll
stickyToggles relative ↔ fixed on scroll threshold

Used with top, right, bottom, left, z-index.

10

Flexbox — 1D layout

.container {
  display: flex;
  flex-direction: row | column;
  justify-content: flex-start | center | space-between | space-around;
  align-items: stretch | center | flex-start | flex-end;
  flex-wrap: wrap | nowrap;
}
.item {
  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: auto;
}
11

Grid — 2D layout

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: auto;
  gap: 10px;
}
.item {
  grid-column: 1 / 3;
  grid-row: 1 / 2;
}

Common Values

  • overflow: hidden | scroll | auto
  • opacity: 0 to 1
  • cursor: pointer
  • box-shadow: 2px 2px 5px rgba(0,0,0,0.3)
  • text-shadow: 1px 1px 2px gray

23

Best Practices

  • Use external CSS files, not inline styles
  • Prefer classes over IDs for styling hooks
  • Use rem/em for scalable, responsive sizing
  • Use Flexbox/Grid over floats for layout
  • Keep specificity low — avoid !important
  • Design mobile-first, then layer on media queries
