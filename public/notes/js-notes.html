JavaScript — Full Short Notes

Ek complete, beginner-friendly reference revision mate: variables, functions, arrays/objects, closures, promises ane DOM — dar code block pehla simple explanation sathe.

01

What is JavaScript

Simple bhasha ma: JavaScript ek programming language chhe je webpages ne interactive banave chhe — HTML structure ape chhe, CSS style ape chhe, ane JavaScript behavior/logic ape chhe (clicks, animations, data fetching, etc). It runs directly in the browser, and also on servers via Node.js.
  • Dynamically typed — variable no type runtime par decide thay chhe, fixed nathi hoto
  • Interpreted — line-by-line run thay chhe, alag compile step vagar
  • Single-threaded but asynchronous — ek time e ek kaam, pan slow tasks ne background ma handle kare chhe (event loop)
  • Everything is loosely connected via objects — even functions are objects
02

Variables

Variable ek named container chhe jema value store thay chhe. let ane const modern standard chhe; var jauni style chhe ane sambhaline vaparvi joiye (scope-related issues aape chhe).
let age = 21;       // can be reassigned
const name = "Sam";  // cannot be reassigned
var old = true;     // old style — function-scoped, avoid in new code
03

Data Types

7 primitive types + object. Primitives store a single value directly; objects (including arrays, functions) store a reference to a collection of data.

typeof "hi";   // "string" — check a value's type
04

Operators

== comparing pehla type convert (coerce) kare chhe, pan === type ane value banne check kare chhe. Best practice: hammesha === vapro.
5 == "5"    // true — loose equality, type coerced
5 === "5"   // false — strict equality, different types
a ?? b     // nullish coalescing — b only if a is null/undefined
a ?.b     // optional chaining — safely access nested props
05

Conditionals

Program ne different path par decide karva de chhe, condition true chhe ke false depend karta.
if (age >= 18) {
  console.log("Adult");
} else if (age > 12) {
  console.log("Teen");
} else {
  console.log("Child");
}
06

Loops

Code ne repeatedly run karva mate — count karva, array par iterate karva, ke condition sudhi repeat karva mate.
for (let i = 0; i < 5; i++) {
  console.log(i);
}

for (const fruit of fruits) { // iterate over values
  console.log(fruit);
}

while (n > 0) { n--; }  // runs while condition stays true
07

Functions

Function ek reusable block of code chhe je input (parameters) le shake chhe ane output (return value) aapi shake chhe.
function add(a, b) {
  return a + b;
}

add(3, 4);   // 7 — calling the function
08

Arrow Functions

Function lakhva no shorter syntax. Important difference: arrow functions ni potani this nathi hoti — te surrounding (parent) scope mathi this le chhe.
const add = (a, b) => a + b;  // short syntax, implicit return

const square = x => {
  return x * x;   // explicit return needed with { }
};
09

Scope & Hoisting

Scope decide kare chhe variable kya accessible chhe. Hoisting no matlab chhe ke declarations (var, function) code run thava pehla "upar khenchai" jay chhe — pan let/const initialize thay ta sudhi "temporal dead zone" ma rahe chhe.
console.log(x);   // undefined, not an error — var is hoisted
var x = 5;

{
  let y = 10;  // y exists only inside this block
}
// y is not accessible here
10

Closures

Closure ek function chhe je potani outer function ni variables ne "yaad" rakhe chhe, outer function finish thaya pachi pan. Data privacy ane counters/generators banavva mate vapraay chhe.
function makeCounter() {
  let count = 0;
  return function() {
    count++;
    return count;   // still remembers `count` from outer scope
  };
}

const counter = makeCounter();
counter(); // 1
counter(); // 2
11

Arrays

Array ek ordered list chhe je multiple values ekj variable ma store kare chhe, 0 thi start thata index thi access thay chhe.
const fruits = ["apple", "banana", "cherry"];
fruits[0];          // "apple" — first item
fruits.length;      // 3
fruits.push("date");  // adds to the end
12

Array Methods

map, filter, reduce — ah trane original array ne change karya vagar naya result banave chhe (immutable style), je modern JS ma bahu common chhe.
const nums = [1, 2, 3, 4];

nums.map(n => n * 2);         // [2,4,6,8] — transform each item
nums.filter(n => n % 2 === 0); // [2,4] — keep matching items
nums.reduce((sum, n) => sum + n, 0);  // 10 — collapse to one value
nums.find(n => n > 2);         // 3 — first match
13

Objects

Object key-value pairs ma data store kare chhe — real-world "things" (jem ke ek user) model karva mate.
const user = {
  name: "Sam",
  age: 25,
  greet() { console.log("hi"); }
};

user.name;       // "Sam" — dot notation
user["age"];   // 25 — bracket notation, useful for dynamic keys
14

Destructuring

Array ke object mathi values ne directly variables ma "unpack" karva ni shortcut — separate lines lakhva ni jarur nathi padti.
const { name, age } = user;       // pulls user.name and user.age out
const [first, second] = fruits;  // pulls first two array items
15

Spread & Rest

Same ... syntax, do kaam mate: spread ek collection ne "khole" chhe (copy/merge mate), rest extra values ne ekathi array ma "bhege" chhe.
const arr2 = [...nums, 5];      // spread — copies nums, adds 5
const merged = {...user, age: 30};  // spread — merges + overrides age

function sum(...nums) {       // rest — gathers all args into an array
  return nums.reduce((a,b)=>a+b);
}
16

The "this" Keyword

this function kai rite call thay chhe teni par depend kare chhe — hammesha "kon owns karyu" e nathi hotu. Object method ma call thay to this = object; arrow function ma this = surrounding scope nu.
const obj = {
  name: "Sam",
  greet() { console.log(this.name); }  // `this` = obj, prints "Sam"
};
17

Classes

Object create karva mate no blueprint syntax — objects, methods ane inheritance banavvana traditional ways than clean rite kaam kare chhe. Andar thi hajipan prototypes j vapra chhe.
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    console.log(this.name + " makes a sound");
  }
}

const dog = new Animal("Rex");
dog.speak();   // "Rex makes a sound"
18

Promises & Async/Await

Promise ek "future value" ne represent kare chhe — jem ke ek API call no result — je pending, fulfilled, ke rejected ho shake. async/await promise-based code ne normal, top-to-bottom code jevu dekhad chhe.
async function getUser() {
  try {
    const res = await fetch("/api/user");  // waits without blocking the thread
    const data = await res.json();
    return data;
  } catch (err) {
    console.error("Failed:", err);
  }
}
19

Event Loop

JavaScript single-threaded chhe — ek time e ek kaam. Event loop check karto rahe chhe ke call stack khali chhe ke nahi, ane pachi pending async kaam (jem ke timer, fetch result) ne queue mathi run karva de chhe.
call stack
runs sync code now
web APIs
timers, fetch run here
callback queue
waits its turn
Stack khali thay pachi j event loop queue mathi next kaam stack ma move kare chhe — evu ma promises are prioritized before setTimeout callbacks.
20

DOM & Events

DOM (Document Object Model) webpage nu structure JS thi accessible object tree tarike represent kare chhe — atle JS thi elements select, change, ke create kari shakay chhe.
const btn = document.querySelector("#myBtn");
btn.textContent = "Click me";       // change displayed text

btn.addEventListener("click", () => {
  console.log("Button clicked!");
});
21

JSON & Error Handling

JSON data ne text tarike store/transfer karva no format chhe (APIs ma bahu common). try/catch runtime errors ne program crash thata pehla handle kare chhe.
JSON.stringify(user);   // object → JSON text
JSON.parse(jsonText);   // JSON text → object

try {
  riskyOperation();
} catch (error) {
  console.log("Error:", error.message);
}
22

Best Practices

  • let/const vapro, var avoid karo
  • Hammesha === vapro, == nahi (loose equality bugs aapi shake)
  • Array/object ne directly mutate karva na badle naya copies banavo (immutability)
  • Async code ma hammesha errors handle karo (try/catch)
  • Functions ne small ane single-purpose rakho
  • Meaningful variable/function names vaparo, short cryptic names nahi
